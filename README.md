# Python ATM Simulator

A command-line banking simulator built in Python that lets users log in and manage a virtual bank account.

## Features
- **Account & PIN Verification:** Checks account numbers and locks access after too many wrong PIN attempts.
- **Balance & Transactions:** Lets users check their balance, deposit funds, and withdraw money safely.
- **Error Handling:** Prevents invalid inputs and overdrafts.

## How to Run
1. Make sure you have Python installed.
2. Download `atm.py` and run it in your terminal:
   ```bash
   python atm.py
   ```
